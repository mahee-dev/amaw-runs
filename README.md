# amaw-runs

Recorded provider-backed games of [AMAW](https://github.com/mahee-dev/AIMatrixWargames), the
Autonomous Matrix Wargame Platform. Each directory is one run, or one batch: the full
administrative export of every game (`export.json` or `exports/`), the run manifest and logs.

What each run showed is written up in the main repository's
[`dev/RUNS.md`](https://github.com/mahee-dev/AIMatrixWargames/blob/main/dev/RUNS.md). An entry
there cites its evidence as `amaw-runs/<dir>/` or, for later runs, `dev/runs/<dir>/`. Both mean
the directory of the same name here.

**Exports are administrative records.** They contain every Actor's objectives, private briefs,
private Messages and notes. The games are LLM agents playing fictional or frozen scenarios, not
forecasts, and nothing in them is advice.

Held back for now: the adjudication-corpus runs (runs 20 and 21), which are built from cases
derived from the `ai-2027` scenario, until that scenario's authors agree to its publication.
